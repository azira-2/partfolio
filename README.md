# Shaxsiy portfolio

Vite, React, TypeScript va Tailwind CSS v4 yordamida yaratilgan moslashuvchan portfolio. Shaxsiy ma’lumotlar `src/data.ts` faylida jamlangan.

## Loyihani ishga tushirish

```sh
npm install
npm run dev
```

Ishlab chiqarish versiyasini yaratish uchun `npm run build` buyrug‘ini bajaring.

## O‘zingizga moslash

- Ism, manzil, elektron pochta, tanishtiruv matni, tarjimai hol va profil rasmi manzilini `src/data.ts`da o‘zgartiring.
- GitHub, LinkedIn va Telegram havolalarini shu faylga kiriting.
- Ko‘nikmalar, namunaviy loyihalar, tajriba va statistika ma’lumotlarini o‘zingiznikiga almashtiring.
- `public/cv-placeholder.txt` faylini rezyumeingiz bilan almashtiring. Boshqa nom ishlatsangiz, `src/App.tsx`dagi yuklab olish havolasini ham yangilang.
- Nashr qilishdan oldin Unsplash rasmlarini o‘zingizning optimallashtirilgan rasmlaringiz bilan almashtiring.
- Aloqa formasi hozircha faqat interfeysdan iborat. Xabar yuborish uchun backend yoki elektron pochta xizmatiga ulang.
